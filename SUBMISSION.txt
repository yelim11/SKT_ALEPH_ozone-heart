BR-B 제출문

1. 결과물
- 실행 묶음: BRB_OzoneHeartRune.zip
- 공개 URL: GitHub Pages 업로드 후 여기에 최종 URL 입력

2. 앱 한 문장
2025년 4~6월 서울 91일 분석에서 기온과 오존의 단순한 양의 상관이 확인되지 않았기 때문에, 야외활동을 준비하는 사람이 기온만 보고 오존을 추측하지 않고 실제 오존 값을 함께 확인하도록 돕는 앱입니다.

3. 사용자가 할 일 세 가지
① 기온을 입력하고 ‘오존 하트 체크’를 누른다.
② ‘서울 현재값 자동 확인’을 누르거나 오존 값을 직접 입력한다.
③ ‘오늘의 기록에 저장’을 눌러 최근 체크값을 비교한다.

4. 짧은 확인 방법
- 위치: index.html 첫 화면에서 논문 제목과 앱 한 문장을 확인합니다.
- 행동 1: 기온 28만 입력하고 오존 값은 비운 뒤 ‘오존 하트 체크’를 누릅니다.
- 통과 1: ‘판단 보류: 기온만으로 오존을 예측하지 않습니다’와 r=-0.0697, p=0.5115가 나옵니다.
- 행동 2: ‘예시 데이터로 체험’을 누릅니다.
- 통과 2: 28.0°C / 110.0 µg/m³가 표시되고, 기온 때문에 오존이 높아졌다고 단정하지 않는 설명이 나옵니다.
- 행동 3: ‘오늘의 기록에 저장’을 누릅니다.
- 통과 3: ‘오늘의 기록’에 값이 추가됩니다.
- 잘못된 입력: 기온 999를 넣으면 앱이 멈추지 않고 ‘-40~60°C 사이 숫자’를 입력하라는 안내가 나옵니다.

5. 논문 결과 적용 근거
- 2025년 4~6월 서울 91일 분석
- Pearson r=-0.0697
- p=0.5115
- 전체 표본에서 단순한 양의 관계가 확인되지 않았으므로, 앱은 기온 단독 입력 시 오존을 예측하지 않고 실제 오존 값을 추가로 확인하도록 설계했습니다.

6. 개인정보와 비밀값
- 실제 개인정보 없음
- 비밀번호·토큰·API 키 없음
- 예시 데이터만 사용

7. AI와 나의 판단 세 줄
① AI에게 맡긴 일: 논문 결과를 앱의 규칙으로 바꾸고, 입력 검증·현재값 확인·기록 저장 기능과 쇼콜라/듀크 및 보석 하트 콘셉트의 정적 웹 코드를 만드는 일을 맡겼습니다.
② 내가 직접 판단한 일: 예상과 다른 논문 결과를 억지로 ‘기온이 높으면 오존이 높다’로 바꾸지 않고, ‘기온만으로는 판단하지 않는다’를 앱의 핵심 규칙으로 쓰기로 판단했습니다.
③ AI 제안을 따르지 않은 일: 오존 값을 임의의 안전/위험 등급으로 단정하는 기능은 논문 결과가 아니므로 넣지 않았고, 보석 하트 색은 데이터 상태만 표현하도록 정했습니다.
