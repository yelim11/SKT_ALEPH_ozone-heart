3. 앱 한 문장
서울에서 외출 전 대기질을 판단하려는 사람이 기온 하나만 보고 오존 수준을 단정하지 않도록, 2025년 4~6월 서울 91일 연구 결과와 실제 원자료를 이용해 기온 구간·오존 자료값·연구 결론을 함께 보여주는 앱입니다.

4. 짧은 확인 방법
- 25 입력 → Q4 높은 기온 구간 / 평균 O₃ 자료값 0.03600
- 22.8 입력 → Q3 / 평균 O₃ 0.04536 / 실제 2025-06-16 22.8°C O₃ 0.0691 확인
- 40 입력 → 연구 범위 밖, 계산하지 않음
- 빈칸 → 숫자 입력 안내, 앱은 멈추지 않음

5. AI와 나의 판단
① AI에게 맡긴 일: 논문 통계와 91일 원자료를 앱 기능으로 옮기고 입력 검증, 반응형 UI, 확인 문서를 구현하게 했다.
② 내가 직접 판단한 일: 현재 오존을 예측하지 않고 ‘기온 하나로 오존을 단정하지 않도록 돕는 앱’으로 기능 목표와 사용자 흐름을 정했다.
③ AI 제안을 따르지 않은 일: ‘더우면 오존이 높다’는 표현은 논문의 유의하지 않은 결과와 맞지 않아 사용하지 않았고, 논문 결론과 외삽 금지를 우선했다.
