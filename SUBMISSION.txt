3. 앱 한 문장
서울에서 외출 전 대기질을 확인하려는 사람이 현재 오존 상태와 외출 행동요령을 빠르게 판단하고, 기온 하나만으로 오존을 단정하지 않도록 과제 10의 91일 연구 결과를 함께 보여주는 앱입니다.

4. 사용자가 할 일 3가지
① 에어코리아에서 현재 서울 O₃ 시간자료 값을 확인한다.
② 앱에 ppm 값을 입력하고 필요하면 민감군 기준을 선택한다.
③ 좋음/보통/나쁨/매우나쁨 상태, 외출 행동요령, 비슷한 오존값의 실제 연구일과 논문 결론을 확인한다.

5. 짧은 확인 방법
- 0.025 입력 → 좋음 / “외출해도 괜찮아요.”
- 0.060 입력 → 보통 / 일반인은 외출 가능 안내
- 0.120 입력 → 나쁨 / 장시간·무리한 실외활동 제한 안내
- 0.180 입력 → 매우나쁨 / 외출 제한·실내생활 권고
- 민감군 체크 후 0.180 입력 → “가능하면 실내에 머무르세요.”
- 빈칸 또는 음수 입력 → 오류 안내 후 앱이 멈추지 않음

6. 논문 결과가 실제로 쓰이는 부분
과제 10의 2025년 4~6월 서울 91일 원자료와 Pearson r=-0.070, p=0.511 결과를 사용한다. 논문에서 기온과 오존의 유의한 관계가 확인되지 않았기 때문에 앱은 기온으로 현재 오존을 예측하지 않는다. 대신 실제 오존값을 기준으로 행동요령을 안내하고, 입력값과 비슷한 O₃ 연구일 3개와 당시 기온을 보여준다.

7. AI와 나의 판단
① AI에게 맡긴 일: 논문 통계와 91일 원자료를 앱 기능으로 옮기고, 에어코리아 등급 기준에 따른 상태 판정·입력 검증·반응형 UI를 구현하게 했다.
② 내가 직접 판단한 일: 사용자가 실제로 알고 싶은 “오늘 나가도 되는가”를 메인 기능으로 정하고, 현재 오존값을 기준으로 행동요령을 보여주도록 했다.
③ AI 제안을 따르지 않은 일: 기온만으로 현재 오존을 예측하는 방식은 논문 결과와 맞지 않아 사용하지 않았다.
