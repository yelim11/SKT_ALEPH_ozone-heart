# BR-B | OZONE HEART RUNE

과제 10의 「서울 기온과 오존 관계 탐구」 결과를 실제 사용 흐름으로 바꾼 정적 웹 애플리케이션입니다.

## 앱 한 문장

2025년 4~6월 서울 91일 분석에서 기온과 오존의 단순한 양의 상관이 확인되지 않았기 때문에, 야외활동을 준비하는 사람이 기온만 보고 오존을 추측하지 않고 실제 오존 값을 함께 확인하도록 돕는 앱입니다.

## 논문 결과를 어떻게 쓰는가

- 표본: 2025년 4~6월 서울 91일
- 전체 Pearson r = -0.0697
- p = 0.5115
- 핵심 규칙: **기온만 입력되면 오존을 예측하지 않고 “판단 보류”를 보여 준다.**
- 실제 오존 값이 있으면 그 값을 그대로 보여 주되, 기온 때문에 높아졌다고 인과를 단정하지 않는다.

## 사용자가 할 일 3가지

1. 기온을 입력하고 `오존 하트 체크`를 눌러, 온도만으로는 오존을 예측하지 않는 결과를 확인합니다.
2. `서울 현재값 자동 확인`을 누르거나 실제 오존 값을 직접 입력해 기온과 오존을 함께 확인합니다.
3. `오늘의 기록에 저장`을 눌러 최근 체크값을 비교합니다.

## 실행 방법

### 가장 쉬운 방법

`index.html`을 더블클릭해 브라우저로 엽니다.

### 로컬 서버로 실행

Python이 설치되어 있다면 이 폴더에서 다음 중 하나를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages에 올리는 방법

1. 이 폴더의 `index.html`, `style.css`, `app.js`, `assets` 폴더를 새 GitHub 저장소 루트에 업로드합니다.
2. 저장소 `Settings` -> `Pages`로 이동합니다.
3. `Deploy from a branch` -> `main` / `(root)`를 선택합니다.
4. 생성된 공개 URL을 새 시크릿 창에서 확인합니다.

외부 라이브러리, 로그인, API 키가 필요하지 않습니다.

## 현재값 자동 확인

서울 시청 기준 좌표에서 공개 Open-Meteo Weather API와 Air Quality API를 사용합니다. 네트워크 요청이 실패해도 앱은 멈추지 않고 수동 입력과 예시 데이터 기능을 제공합니다.

## 개인정보 / 비밀값

- 실제 개인정보 없음
- 비밀번호, 토큰, API 키 없음
- 예시 체험 데이터: 28.0°C / 110.0 µg/m³
- 브라우저 기록은 해당 브라우저의 localStorage에만 최대 7개 저장됩니다.

## 콘셉트

- 사용자가 제공한 콘셉트 이미지를 왼쪽 캐릭터 패널에 사용했습니다.
- 쇼콜라의 송곳니가 보이는 캐릭터 아트와 듀크가 첫 화면에 함께 보입니다.
- 일반 이모지 아이콘 대신 CSS로 만든 보석형 하트가 상태를 표현합니다.
- 하트 색은 공식 대기질 위험 등급이 아니라 데이터 상태(판단 보류 / 실시간 / 직접 입력 / 예시)를 뜻합니다.

## 잘못된 입력 / 실패 처리

- 기온이 비어 있거나 -40~60°C 범위를 벗어나면 안내문을 보여 줍니다.
- 오존 값이 0~1000 µg/m³ 범위를 벗어나면 안내문을 보여 줍니다.
- API가 실패하거나 시간이 초과되면 오류 이유를 표시하고 수동 입력 / 예시 체험을 계속 사용할 수 있습니다.
- localStorage 저장이 불가능해도 체크 기능은 계속 동작합니다.
