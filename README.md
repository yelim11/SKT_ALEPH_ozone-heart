# 오존 하트 체크 앱

1. `index.html`을 열면 바로 실행됩니다.
2. GitHub Pages에 올릴 때는 이 폴더 안의 파일을 그대로 저장소 루트에 업로드하면 됩니다.
3. 기온을 입력하고 화면의 **오존 하트 체크하기** 버튼을 누르면 하트 색상으로 결과가 표시됩니다.
4. **BGM**
   - 화면 오른쪽 위 `음악 넣기`에서 MP3/WAV 등을 직접 선택할 수 있습니다.
   - 배포할 때 항상 같은 BGM을 쓰고 싶다면 원하는 음원을 `assets/bgm.mp3` 이름으로 넣으면 됩니다.
   - 브라우저 정책상 첫 재생은 사용자가 BGM 버튼을 눌러야 할 수 있습니다.
5. 저작권이 있는 애니메이션 원본 음원은 패키지에 포함하지 않았습니다. 사용할 권리가 있는 음원을 직접 넣어 주세요.
6. 앱의 오존 단계는 **기온이 높을수록 오존 농도가 높아질 수 있다**는 연구 결과를 쉽게 보여주기 위한 시각화입니다. 실제 오존 측정값 자체를 예측하는 모델은 아닙니다.
