# 쇼콜라와 보는 오존도 — BR-B

과제 10 논문 **「2025년 오존 시즌 서울의 일평균 기온과 일별 오존 자료값의 관계」**의 실제 결과를 사용하는 정적 웹 애플리케이션입니다.

## 앱 한 문장
서울에서 외출 전 대기질을 확인하려는 사람이 **기온만으로 오존을 판단하지 않도록**, 논문의 91일 분석 결과와 기온 구간별 실제 O₃ 연구값을 보여 주고 공식 대기질 정보도 함께 확인하도록 안내하는 앱입니다.

## 사용자가 할 일 세 가지
1. 확인하고 싶은 일평균 기온을 숫자로 입력합니다.
2. `분석하기` 버튼을 누릅니다.
3. 기온 구간 결과를 확인하고 `논문 실제 근거 보기`를 눌러 논문에 제시된 실제 대표 연구일을 확인합니다.

## 논문 결과를 실제로 쓰는 부분
- 분석 기간: 2025-04-01 ~ 2025-06-30, 서울 91일
- Pearson r = -0.0697, p = 0.5115
- Spearman ρ = -0.0479, p = 0.6518
- 단순회귀 R² = 0.00486
- 기온 사분위 경계: 14.35°C / 19.20°C / 23.05°C
- Q1 평균 O₃ = 0.03837
- Q2 평균 O₃ = 0.03687
- Q3 평균 O₃ = 0.04536
- Q4 평균 O₃ = 0.03600

앱은 입력값을 위 사분위에 배치해 해당 구간의 실제 평균값을 보여줍니다. `논문 실제 근거 보기`에서는 논문 원자료에 제시된 대표 날짜 3개(2025-06-19, 2025-06-30, 2025-06-16)를 실제 사례로 보여줍니다. 연구 범위 4.5~28.8°C 밖의 값은 임의 예측하지 않습니다.

## 오류 입력 확인
- 빈칸: 숫자를 입력하라는 안내가 나옵니다.
- 숫자가 아닌 값: 숫자 입력 안내가 나옵니다.
- -80°C 미만 또는 70°C 초과: 입력값 재확인 안내가 나옵니다.
- 논문 관측 범위 4.5~28.8°C 밖: 앱은 멈추지 않고 `해석 보류`로 표시합니다.
