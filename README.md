# 서울 오존 가이드

BR-B · 과제 10 논문 결과를 실제로 사용하는 웹 애플리케이션

## 논문
「2025년 오존 시즌 서울의 일평균 기온과 일별 오존 자료값의 관계」

## 앱 한 문장
서울에서 외출 전 대기질을 판단하려는 사람이 기온 하나만 보고 오존 수준을 단정하지 않도록, 2025년 4~6월 서울 91일 연구 결과와 실제 원자료를 이용해 기온 구간·오존 자료값·연구 결론을 함께 보여주는 앱입니다.

## 사용자가 할 일 3가지
1. 일평균 기온을 입력합니다.
2. 논문에서 사용한 기온 사분위 구간과 해당 구간의 평균 O₃ 자료값을 확인합니다.
3. 입력 기온과 가까운 실제 연구일 3개와 “기온만으로 오존을 단정하기 어렵다”는 연구 결론을 함께 확인합니다.

## 논문 결과를 실제로 쓰는 부분
- 분석 표본: 91일
- Pearson r = -0.0697004497
- Pearson p = 0.5114976192
- Spearman rho = -0.0479415782
- Spearman p = 0.6517942274
- R² = 0.0048581527
- 기온 사분위 경계: 4.5 / 14.35 / 19.2 / 23.05 / 28.8 °C
- 사분위 평균 O₃ 자료값: Q1 0.038365 / Q2 0.036867 / Q3 0.045362 / Q4 0.036000

앱은 이 결과 때문에 “기온이 높으면 오존도 높다”고 예측하지 않습니다. 관측 범위를 벗어난 입력은 외삽하지 않고 범위 밖이라고 안내합니다.

캐릭터·보석 컨셉을 제거하고 연구 결과가 먼저 보이는 깔끔한 데이터 대시보드 형태로 다시 제작했습니다.
- 네이비·블루·틸 중심의 차분한 색상

- 91일 원자료 산점도에서 가까운 연구일 강조
