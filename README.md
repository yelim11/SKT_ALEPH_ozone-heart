# 서울 오존 가이드

BR-B · 과제 10 논문 결과를 실제 사용자 행동으로 연결한 웹 애플리케이션

## 논문
「2025년 오존 시즌 서울의 일평균 기온과 일별 오존 자료값의 관계」

## 앱 한 문장
서울에서 외출 전 대기질을 확인하려는 사람이 현재 오존 상태와 외출 행동요령을 빠르게 판단하고, 기온 하나만으로 오존을 단정하지 않도록 과제 10의 91일 연구 결과를 함께 보여주는 앱입니다.

## 사용자가 할 일 3가지
1. 에어코리아에서 현재 서울 오존(O₃) 시간자료 값을 확인합니다.
2. 앱에 ppm 값을 입력하고 필요하면 민감군 기준을 선택합니다.
3. 오존 상태(좋음/보통/나쁨/매우나쁨), 외출 행동요령, 비슷한 오존값의 실제 연구일과 논문 결론을 확인합니다.

## 오존 상태 기준
에어코리아 오존 예보등급을 사용합니다.
- 좋음: 0 ~ 0.0300 ppm
- 보통: 0.0301 ~ 0.0900 ppm
- 나쁨: 0.0901 ~ 0.1500 ppm
- 매우나쁨: 0.1500 ppm 초과

앱은 일반인과 민감군에 대해 에어코리아 행동요령을 구분해 보여줍니다.

## 논문 결과를 실제로 쓰는 부분
- 분석 표본: 91일
- Pearson r = -0.0697004497
- Pearson p = 0.5114976192
- Spearman rho = -0.0479415782
- Spearman p = 0.6517942274
- R² = 0.0048581527

논문에서는 “기온이 높을수록 오존도 높을 것”이라는 가설이 이 표본에서 지지되지 않았습니다. 그래서 앱은 기온으로 현재 오존을 예측하지 않습니다. 대신 사용자가 입력한 실제 오존값을 기준으로 행동요령을 안내하고, 91일 원자료에서 비슷한 오존값의 날짜와 당시 기온을 보여줍니다.
