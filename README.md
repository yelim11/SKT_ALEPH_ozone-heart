# 쇼콜라와 보는 오존도

과제 10 논문 **「2025년 오존 시즌 서울의 일평균 기온과 일별 오존 자료값의 관계」**의 결과를 실제로 사용하는 BR-B 웹 애플리케이션입니다.

## 누구를 어떻게 돕는가
서울에서 외출 전 대기질을 확인하려는 사람이 **기온만으로 오존을 판단하지 않도록**, 논문에서 확인한 91일 자료와 분석 결과를 바탕으로 기온 구간 비교와 실제 관측 사례를 보여줍니다.

## 사용 방법
1. 첫 화면에서 확인하고 싶은 일평균 기온을 숫자로 입력합니다.
2. `분석하기`를 누릅니다.
3. 해당 기온 구간의 평균 O₃ 자료값, 논문의 핵심 결론, 입력값과 가까운 실제 연구일을 확인합니다.

예시 입력: `25`

## 논문 결과를 실제로 쓰는 부분
- 분석 기간: 2025년 4월~6월, 서울 91일
- Pearson r = -0.070, p = 0.511
- Spearman ρ = -0.048, p = 0.652
- R² = 0.00486
- 기온 사분위 기준: 14.35°C / 19.2°C / 23.05°C
- Q1 평균 O₃ = 0.03837
- Q2 평균 O₃ = 0.03687
- Q3 평균 O₃ = 0.04536
- Q4 평균 O₃ = 0.03600

앱은 입력 기온을 논문에서 사용한 기온 사분위 구간에 배치하고, 해당 구간의 실제 평균 O₃ 자료값과 입력 기온에 가장 가까운 실제 연구일 3개를 보여줍니다. 논문 관측 범위인 4.5~28.8°C 밖의 입력에는 임의 예측을 하지 않고 범위 밖이라고 안내합니다.

## 개인정보·비밀값
실제 개인정보, 비밀번호, 토큰, API 키를 사용하지 않습니다. 앱에는 논문 분석에 사용한 연구 자료와 결과만 포함되어 있습니다.
