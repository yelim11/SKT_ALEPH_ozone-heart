[BR-B 짧은 확인 방법]

결과물 URL
https://yelim11.github.io/SKT_ALEPH_ozone-heart/

1. 0.025 입력 → 외출 판단하기
- 현재 오존 상태: 좋음
- “외출해도 괜찮아요.”
가 나오면 통과.

2. 0.060 입력 → 외출 판단하기
- 현재 오존 상태: 보통
- 일반인은 특별한 행동 제한 없이 활동할 수 있다는 안내
가 나오면 통과.

3. 0.120 입력 → 외출 판단하기
- 현재 오존 상태: 나쁨
- 장시간 또는 무리한 실외활동 제한 안내
가 나오면 통과.

4. 0.180 입력 → 외출 판단하기
- 현재 오존 상태: 매우나쁨
- 일반인은 외출을 줄이고 실내생활 권고
가 나오면 통과.

5. 민감군 기준 체크 + 0.180 입력
- “가능하면 실내에 머무르세요.”
- 가급적 실내활동 안내
가 나오면 통과.

6. 잘못된 입력 확인
- 빈칸 → 현재 오존값을 숫자로 입력하라는 안내
- 음수 → 0 이상의 값을 입력하라는 안내
- 1 초과 → ppm 단위를 확인하라는 안내
- 어느 경우에도 앱이 멈추지 않으면 통과.

7. 논문 반영 확인
- 논문 제목이 보인다.
- 91일 / Pearson r=-0.070 / p=0.511이 보인다.
- 현재 오존을 기온으로 예측하지 않는 이유가 설명된다.
- 입력한 O₃ 값과 비슷한 실제 연구일 3개가 나타난다.
가 모두 확인되면 통과.

8. 공개 확인
새 시크릿 창에서 URL을 열었을 때 로그인·인증·초대·비밀번호 없이 바로 열리면 통과.
